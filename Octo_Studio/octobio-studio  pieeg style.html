Starter kit: read

kit.sound · kit.moistureraw 0–1023
kit.button · kit.motiontrue / false (button D7, PIR)
kit.irlast IR remote code, or null
kit.tilt'left' 'right' 'forward' 'back' 'flat' or null

kit.led2(on)second light (D8)

kit.buzzer(on) · kit.relay(on)true / false. Never put mains on the relay.
